Multithreading in Java FROM VIDEO

Java multithreading support karta hai taaki developers aisi applications bana sakein jo system ke resources ko completely utilize kar sakein.

Definition

Multithreading = concurrent execution of 2 or more threads to maximize CPU utilization.

Simple si baat — CPU ko baitha ke waste nahi karna, uske har moment ko kaam karwana.

Ye capabilities kahan se aati hain?

Java ki multithreading capabilities java.lang package ka part hain — isliye concurrent execution implement karna easy hai. Thread class aur Runnable interface dono isi package mein hain.

Matlab alag se kuch install karne ki zaroorat nahi — saari kahani built-in hai.

02

Single Core vs Multi-Core FROM VIDEO

JVM threads ko handle kaise karta hai — ye is par depend karta hai ki CPU mein ek core hai ya multiple.

Single Core Environment

  • Java ka multithreading JVM aur OS dono manage karte hain
  • Wo threads ke beech switch karte hain — taaki illusion of concurrency mile
  • Saare threads single core ko share karte hain
  • Iske liye Time Slicing use hota hai — har thread ko thoda-thoda time milta hai

Multiple Core Environment

  • Java ka multithreading available cores ka full advantage le sakta hai
  • JVM threads ko multiple cores pe distribute kar sakta hai
  • Isse threads ki true parallel execution possible hoti hai

Pehle sirf OS schedule kar raha tha — ab JVM bhi apna role nibhata hai, threads ko cores pe baant-ta hai.

Thread Basics FROM VIDEO

Thread ki do definitions yaad rakho — dono interview mein kaam aati hain.

  • Thread is a lightweight process
  • Thread is the smallest unit of processing
  • Java multithreading support karta hai apne java.lang ke Thread class aur Runnable interface se

Bonus: Process vs Thread BONUS

Bonus: Concurrency vs Parallelism BONUS

  • Concurrency = tasks ka interleaved hona (ek core pe switch karke) — "ek waqt mein ek, par sab ko time milta hai"
  • Parallelism = tasks ka sach mein simultaneously hona (multiple cores pe) — "ek waqt mein sab"
  • Single core → concurrency (illusion)  |  Multi core → true parallelism

Video wali baat yaad karo: single core pe "illusion of concurrency", multi core pe "true parallel execution".

The Main Thread FROM VIDEO

Sabse important point: Java program start hote hi ek thread immediately run hota hai.

  • When a Java program starts, one thread begins running immediately
  • Us thread ka naam hota hai main thread
  • Ye thread main() method ko execute karne ke liye responsible hota hai

Matlab tumne ab tak saare programs (Hello World bhi) sirf main thread se chalaye ho — abhi actual multithreading use nahi hui!

Proof: Hello World bhi ek process hai

Video mein simple program run kiya:

Main.java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World");
    }
}

Output mein Process finished with exit code 0 dikhta hai — matlab ek process chali, aur us process mein ek hi thread tha: main.

Proof: Thread ka naam khud dekho

Thread.currentThread().getName() — chalane wale thread ka naam batata hai:

Main.java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World");
        System.out.println(Thread.currentThread().getName());
    }
}
Output
Hello World
main
Process finished with exit code 0

Output "main" — proof ho gaya ki main thread hi chal raha tha.

Predict the Output BONUS

Concept check — dimaag mein chalao, phir option dabao.

Test.java
public class Test {
    public static void show() {
        System.out.println(Thread.currentThread().getName());
    }
    public static void main(String[] args) {
        System.out.println(Thread.currentThread().getName());
        show();
    }
}
Answer: B — show() bhi usi main thread se call ho raha hai (main() → show()). Naya thread kabhi create hi nahi hua, isliye dono jagah "main" print hoga.
Test.java
public class Test {
    public static void main(String[] args) {
        System.out.println(Thread.currentThread().getName());
    }
}
Answer: C — Java program start hote hi main thread immediately run hota hai, aur wahi main() execute karta hai. Uska naam hota hai "main".
