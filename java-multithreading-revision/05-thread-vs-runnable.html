Kab kya use karein? FROM VIDEO

Dono tarike dekh chuke hain — ab sawal: kaunsa kab?

The Rule

  • Agar class already kisi doosri class ko extend kar rahi hai → implements Runnable karna padega
  • Kyunki Java mein multiple inheritance nahi hota — ek class sirf ek hi class extend kar sakti hai
  • Waise (agar koi constraint nahi hai) → koi bhi use kar sakte ho

Video ka example — problem wala case

MyClass already A ko extend kar rahi hai. Ab iska thread banana hai:

MyClass.java
class A { }

// MyClass already A ko extend kar raha hai...
class MyClass extends A implements Runnable {  // solution!
    @Override
    public void run() { // thread ka kaam }
}

Agar yahan extends Thread likhte — toh compiler error: class cannot extend multiple classes. Tab bhi IDE khud suggestion deta hai: "implement the run method" — matlab Runnable hi bacha hai.

Majboori tab hoti hai jab class pehle se kisi ko extend kar rahi ho — tab Runnable hi ek raasta hai.

Already extending something? → Runnable. Warna dono chalega.
Real projects mein bhi Runnable preferred hai (Video 3 ke bonus mein bhi discuss kiya tha)
