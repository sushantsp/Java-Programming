2 Ways to Create Threads

Engineering Digest • Java Multithreading • Video 3 • Revision
0%
01

Overview FROM VIDEO

Naya thread banane ke 2 tarike hain Java mein.

To create a new thread in Java, you can either:

  • extends Thread class karke, ya
  • implements Runnable interface karke

Idea simple hai — jo kaam naye thread mein karana hai (jaise "World" print karana), wo ek alag class mein likhna hoga run() method ke andar. Main thread apna kaam (jaise "Hello" print) khud karta rahega.

02

Way 1: extends Thread FROM VIDEO

Jab bhi naye thread mein koi kaam karana ho — sabse pehle class banao, Thread ko extend karo, kaam run() mein likho.

Steps

  1. Nayi class banao (jaise World)
  2. Usko extends Thread karo
  3. run() method override karo — jo kaam karana hai wo isi ke andar likhna
  4. Class ka object banao
  5. Object pe start() call karo

Code — pehle sirf main thread

Video mein pehle ye chalaya — sirf Hello print hua, kyunki World ka object hi nahi bana tha:

Main.java
class World extends Thread {
    @Override
    public void run() {
        for (int i = 0; i < 100000; i++) {
            System.out.println("World");
        }
    }
}

public class Main {
    public static void main(String[] args) {
        for (int i = 0; i < 100000; i++) {
            System.out.println("Hello");
        }
    }
}

Ab World ko bhi chalao

World print karane ke liye — object banao aur start() call karo:

Main.java
public static void main(String[] args) {
    World w = new World();
    w.start();                        // naya thread start!

    for (int i = 0; i < 100000; i++) {
        System.out.println("Hello"); // ye main thread karta hai
    }
}
Output (random interleaved — har run pe alag)

Output mein kabhi Hello, kabhi World — random order mein mixed. Do threads (main + Thread-0) ek saath kaam kar rahe hain.

03

Important Observations FROM VIDEO

Video mein ye points explicitly bataye gaye — interview ke liye bhi important.

1. Output ka order — RANDOM

  • Execution random order mein hota hai — pehle World, phir Hello, phir World... aisa koi fixed pattern nahi hota
  • Kyunki do independent kaam ho rahe hain — dono apni marzi se chalte hain
  • Agar order mein chahiye, toh phir thread ka matlab hi kya? Tab toh sequential hi likhna padega

2. Thread names — khud dekho

Thread.currentThread().getName() lagane pe dikha:

  • main thread ka naam: main
  • naye thread ka default naam: Thread-0
  • Output: main, Thread-0, main, Thread-0... randomly mixed

3. Infinite loop ke neeche code — UNREACHABLE

Agar main() mein infinite loop laga do aur uske neeche kuch bhi likho, toh compiler unreachable statement error deta hai — kyunki control wahan tak pahunch hi nahi sakta.

Isliye neeche likha "Hello" kabhi print hi nahi hota.

04

Way 2: implements Runnable FROM VIDEO

Same kaam, alag style — Runnable interface implement karo.

Steps

  1. Nayi class banao jo implements Runnable kare
  2. run() override karo — kaam wahi likhna
  3. Apni class ka object banao (jaise world)
  4. Thread ka object banao — constructor mein apna object pass karo: new Thread(world)
  5. Thread object pe start() call karo

Catch yahi hai: Runnable mein start() method hota hi nahi — start() sirf Thread class mein hai. Isliye Thread ka object banana padta hai.

Code

Main.java
class World implements Runnable {
    @Override
    public void run() {
        for (int i = 0; i < 100000; i++) {
            System.out.println("World");
        }
    }
}

public class Main {
    public static void main(String[] args) {
        World world = new World();       // kahani wala object
        Thread t1 = new Thread(world);    // Thread mein pass karo
        t1.start();                        // ab naya thread chalega

        for (int i = 0; i < 100000; i++) {
            System.out.println("Hello");
        }
    }
}
Output (random interleaved — har run pe alag)

Same result — Hello aur World dono parallel execute ho rahe hain, randomly mixed.

05

Bonus: start() vs run() BONUS

Sabse classic interview question — is video ke topic ka natural extension.

  • t1.start() → naya thread banta hai, aur wo thread run() ko call karta hai
  • t1.run() → naya thread NAHI banta — run() sidha main thread pe execute hota hai (normal method call jaisa)

Predict the output

Test.java
class World extends Thread {
    @Override
    public void run() {
        for (int i = 0; i < 100000; i++) System.out.println("World");
    }
}

public class Test {
    public static void main(String[] args) {
        World w = new World();
        w.run();   // dhyan se — start() NAHI, run() hai!
        for (int i = 0; i < 100000; i++) System.out.println("Hello");
    }
}
Answer: B — run() direct call karne se naya thread nahi banta. Main thread pehle poora run() (saara World) execute karta hai, phir Hello ka loop chalta hai. Sequential execution, no threading!

Bonus: extends Thread vs implements Runnable — kya better hai? BONUS
